# HypernetsFR

This repository contains the code used to analyse HYPERNETS-vs-satellite ocean-colour match-ups at two French sites, MAFR (turbid Gironde Estuary) and THFR (clear-water lagoon), against four satellite sensor families (Sentinel-3 OLCI, MODIS-Aqua, VIIRS, PACE-OCI). It supports a manuscript targeting *Frontiers in Remote Sensing*, and also produces the figures used in that manuscript.

## Structure

All code is in `/code/`, numbered by pipeline run order (`0_functions.R` through `5_figures.R` — see `CLAUDE.md` for what each stage does). The `/output/` of this code and the `/figures/` it generates live in similarly named folders; any required `/meta/` data (station coordinates, outlier lists, QC audit logs) are stored there too.

New to this repo? Open `manuscript/pipeline-handoff.html` directly in a browser first — it's a curated overview (what this does, how to run it, a pipeline diagram, a function reference for `code/0_functions.R`, and known open items) meant as a faster on-ramp than `CLAUDE.md`, which remains the authoritative, more detailed reference underneath it.

## Data

The base match-up `.csv`/`.sql` files for the real MAFR/THFR sites are generated by the __`Hypernets_matchups`__ software, external to this project. The pipeline is also mid-transition (as of September 2026) to reading directly from the SQLite `.db` files that tool itself ingests from, so it can apply its own explicit per-pixel QC instead of relying on the tool's internal aggregation — see `CLAUDE.md`'s "Data dependency" and derived-sites sections for the current state of that work. None of this external data is stored in the repo.

## Status

This project is under active development and not yet in its final form: several derived-site variants exist purely to validate the `.db`-based reconstruction against the real tool's output before anything is finalised, and a handful of QC thresholds are still marked temporary pending a conversation with the `Hypernets_matchups` author. See `CLAUDE.md` for the authoritative, up-to-date description of the pipeline and its open items.
